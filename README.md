# automation-lab-6

Лабораторная работа №6 — Автоматизация процессов внедрения и поддержки
компьютерных систем. Практическое использование онлайн-инструментов для
автоматизации развёртывания и управления конфигурациями.

## Цель
Освоить методику автоматизации внедрения и поддержки КС, применить
CI/CD, контейнеризацию и управление конфигурациями.

## Структура проекта
- `README.md` — описание проекта
- `requirements.txt` — зависимости Python-проекта
- `.gitignore` — исключаемые файлы
- `.github/workflows/main.yml` — CI-pipeline (GitHub Actions)
- `app/main.py` — пример приложения
- `tests/test_main.py` — пример теста
